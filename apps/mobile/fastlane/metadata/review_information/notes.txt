ChallengeBu! uses email sign-in only — there is NO password field anywhere in the app.
There is nothing to enter in App Store Connect's "Sign-In Information" password
field; leave it blank or put "N/A" there.

Sign-in (App Review demo account):
  Email: appreview42@proton.me

Steps:
  1. Launch → tap "Üniversite e-postanla başla"
  2. Enter appreview42@proton.me
  3. Check KVKK consent → tap "Devam et"
  4. The account signs in immediately — no code, no password, no second screen.
     You land directly on the onboarding wizard (name, pronoun, category, year,
     department, level, hand, availability — phone and photo are optional/
     skippable) the first time, or straight on the main app (Sıralama, Maçlar,
     Profil tabs) on any later sign-in.

Note: earlier review notes mentioned a 6-digit OTP code (424242) entered on a
separate screen. Real users still go through that screen exactly as shown in
the demo video below — they receive a mailed 6-digit code and enter it there.
Only the review account skips it: since the reviewer can't read
appreview42@proton.me's inbox, that one address signs in on a single tap
instead, so the review can proceed without a mailbox. This is a review-only
shortcut, not a change to what real users experience.

About the app:
  ChallengeBu is an independent community tennis ranking app for university players. It is NOT affiliated with, endorsed by, or sponsored by any university. Access is restricted to verified university email addresses purely as a functional sign-up gate (to keep the community to students/faculty/alumni) — this is access control, not a claim of institutional affiliation, and no university name, logo, or branding is used in the app or its metadata.

Pre-populated review data:
  The review account is seeded with a live, ranked leaderboard (9 players), completed match history and profile stats, an incoming pending challenge, and ONE match that is ready to score right now — so every feature can be exercised without waiting for other users. The reviewer can explore: leaderboard categories (Sıralama), profile stats + ELO history (Profil), notifications, settings (including account deletion), messaging with block/report, and the full match lifecycle below.

Demonstrating the FULL match flow (start → score → result):
  1. Open the Maçlar (Matches) tab → the pre-seeded match card shows "Maçı Başlat".
  2. Tap "Maçı Başlat" to start (it is already within the allowed start window).
  3. Enter points to complete the set, then submit the score.
  (You can also tap the "+" to create a brand-new challenge against any seeded opponent, or accept the incoming pending challenge shown in notifications.)

Device notes:
  iPhone-first app (portrait). On iPad it runs in iPhone compatibility mode; core flows work the same.

Messaging (Guideline 1.2):
  In-thread ⋯ menu offers Report and Block. Blocked users can be managed under Settings → Engellenen kullanıcılar. Messaging requires an active match offer between two users.
