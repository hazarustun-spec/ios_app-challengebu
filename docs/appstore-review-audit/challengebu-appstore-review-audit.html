Kalan Riskler — Öncelik Sırası

R1 · Demo video hâlâ eksikGuideline 2.1 — Information Needed

Neden red? Apple, fiziksel iOS cihazda tüm yeni-kullanıcı onboarding'ini gösteren video istedi; sağlanmazsa otomatik red tekrarı.

"We need a demo video… running on a physical iOS device… the entire new user onboarding experience."

Kontrol: notes.txt'te DEMO_VIDEO_URL hâlâ placeholder; ASC Notes'ta gerçek link var mı?

Düzeltme (SENDE): iPhone ekran kaydı: welcome→e-posta→KVKK→OTP 424242→ana sekmeler→Maçlar'da "Maçı Başlat"→skor→profil→ayarlar. Link'i ASC Notes + notes.txt'e koy.

R2 · Metadata ASC'de canlı değil + screenshot'lar eski2.3.3 / 4.1(a)

Neden red? De-üniversite metin sadece lokal fastlane dosyalarında. Reviewer ASC'deki canlı alanları + screenshot'ları görür; bunlar hâlâ "üniversite adı" içeriyorsa 4.1(a)+2.3 tekrar tetiklenir.

Kontrol: 4 screenshot (fastlane/screenshots/tr/) "Klasik"/"üniversite" gösteriyor mu? ASC Subtitle/Description/Promo güncel mi?

Düzeltme (SENDE): fastlane deliver ile metadata'yı push et (veya ASC'de elle) + rename sonrası screenshot'ları yeniden üret (Maestro), üniversite adı/rozet olmadığını teyit et.

R3 · Seed'i PROD'da çalıştır + yeni build gerekli2.1 / 2.3

Neden red? Seed lokal doğrulandı ama prod DB'de çalışması senin adımın (prod erişimi gerekli). Ayrıca app-içi de-üniversite metin binary'de — build 12 hâlâ eski string taşıyor.

Düzeltme (SENDE): (a) scripts/seed-review-account-production.sql'i Supabase SQL Editor'de çalıştır, verify çıktısını kontrol et. Ön koşul: reviewer bir kez OTP ile giriş yapmış olmalı. (b) EAS ile yeni build (v1.1.0) çıkar, onu submit et.

R4 · Sürüm/build string tutarsızlığı2.3.0

Neden red? app.json version 1.1.0; review edilen 1.0.0 (12). ASC'deki marketing sürüm string'i, gönderilen build'in CFBundleShortVersionString'i ile eşleşmeli.

Düzeltme (SENDE): ASC'de yeni sürümü 1.1.0 olarak aç, build'i ona bağla.

R5 · Privacy Nutrition Label ↔ kod uyumu5.1.1 / 5.1.2

Neden red? ASC App Privacy beyanı toplanan veriyle (e-posta, ad, telefon ops., foto, bölüm, cinsiyet kategorisi) eşleşmeli.

Kontrol/Düzeltme (SENDE): ASC App Privacy'de bu alanları işaretle; "Data Used to Track You" = None (kodda tracking/ATT yok → doğru).

R6 · UGC güvenceleri & diğer — DÜŞÜK (mevcut)1.2 / 4.x / 5.1.1(v)

  • Engelleme/engel kaldırma (settings/blocked.tsx), şikayet, hesap silme (settings/delete-account.tsx + anonymize), terms/privacy/KVKK linkleri — mevcut ✅
  • SIWA gerekmez (sosyal login yok) · ATT gerekmez (tracking yok) · Section 3 N/A (IAP yok) · export compliance ✅ · http link yok ✅
  • İYİLEŞTİR Yaş rating'i UGC/mesajlaşmaya uygun ver; profil adında küfür filtresi; thread içi "Şikayet"in görünürlüğü.

Sende Kalanlar — Yayın Öncesi Checklist

Bunlar prod erişimi / Apple hesabı / fiziksel cihaz gerektirdiği için yalnız sen yapabilirsin.

  • Demo video çek (fiziksel iPhone, tam onboarding + start→score akışı) → ASC → App Review Information → Notes'a link koy (+ notes.txt'teki placeholder'ı doldur). EN KRİTİK
  • Review seed'i PROD'da çalıştır — Supabase SQL Editor → scripts/seed-review-account-production.sql. Önce reviewer bir kez OTP ile giriş yapmış olmalı. Verify çıktısında ladder=9, matches=6, ready=1 gör.
  • Metadata'yı ASC'ye push et (fastlane deliver ya da elle) — Subtitle/Description/Promo/Release-notes/Review-notes.
  • Screenshot'ları yeniden üret (rename sonrası) — hiçbirinde "üniversite adı" görünmesin, ASC'ye yükle.
  • Yeni build (v1.1.0) çıkar (EAS) ve submit et — app-içi de-üniversite metni bu build taşır.
  • ASC sürümünü 1.1.0 aç, build'i bağla (1.0.0 ↔ 1.1.0 tutarsızlığını gider).
  • ASC App Privacy'yi kodla eşle, "tracking = none" bırak.
  • Apple'a mesajla yanıt ver — her iki red kalemine: video linki + "no university affiliation; metadata revised" açıklaması.
  • (Onay sonrası) cleanup-review-seed-production.sql ile demo veriyi temizle.
